# Fleet Manager Roadmap

## Sprint 002A — Foundation

- Game-neutral fleet and entry models
- Construction-profile contract
- P&P priority-budget engine
- Generic points profile
- No-validation profile
- JSON save/load
- Repository profile lookup
- Validation result model

## Sprint 002B — ACTA Rule Extensions

- Purchase groups and two-for-one selections
- Fighter wing quantities and replacements
- Allied fleet allowances
- Unique and maximum-choice limits
- Fleet-specific selection restrictions
- Ancient and Special priority overrides
- Fleet rule providers backed by Codex metadata

## Sprint 002C — Fleet Manager Workspace

- New/open/save fleet
- Faction, fleet/era, year, priority and FAP controls
- Platform navigator
- Roster editing
- Continuous summary and validation
- Platform preview and Codex popovers

## Sprint 002D — Output

- Fleet roster print/export
- Batch platform sheets
- Presentation-theme choice
- Tactical Assistant handoff
