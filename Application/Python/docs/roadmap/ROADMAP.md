# DFS Roadmap

- **1.x — DFS Engine:** database, importer, validator, Codex, PDF generators
- **2.0 — Desktop Foundation:** application shell and reusable query services
- **2.1 — Platform Explorer:** complete browsing, PDF, Codex, comparison, favorites
- **2.2 — Application Framework:** settings, themes, status, notifications, logging, commands
- **2.3 — Fleet Builder:** build, validate, save, print, and export fleets
- **2.4 — Game Mode:** live damage, crew, traits, shields, criticals, and game state
- **2.5 — Campaign Manager:** campaign persistence and post-game progression
- **3.0 — Multi-System Expansion:** Victory at Sea and additional systems
