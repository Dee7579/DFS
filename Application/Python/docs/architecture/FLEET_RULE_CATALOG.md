# DFS Fleet Rule Catalog

The Babylon 5 ACTA Fleet Builder uses one auditable rule catalog. Source priority is Fleet Lists, official FAQ corrections, then Powers & Principalities updates where they supersede earlier material.

Implemented rule families: core priority/year validation, fighter replacements, Earth Alliance missile variants, ISA allied contingents, and Raiders allied contingents.

Catalogued next: Combined League construction, purchase groups, multi-ship purchases, platform limits, fleet-composition restrictions, and remaining FAQ/P&P overrides.
