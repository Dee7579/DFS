# DFS Application Phase 3A

This phase completes the first Ship Viewer polish pass.

## Added

- Year availability filtering using reusable domain logic
- Support for `All`, `YYYY+`, `YYYY-YYYY`, and Unicode dash ranges
- Resizable filter/results/detail panes
- Persistent window geometry, page, pane sizes, expanded filters, and year
- Sheet-like profile stat cards
- Improved result table sizing and row spacing
- Advanced filter grouping
- Active-filter summary
- Selection preservation during refresh
- Double-click focus behavior
- Unit tests for in-service parsing

## Deferred to Phase 3B

- PDF style registry
- Embedded PDF viewer
- front/back controls
- print sheet
- regenerate/open externally

## Deferred to Phase 3C

- Codex links
- linked craft navigation
- navigation history
- platform type icons
