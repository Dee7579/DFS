DFS Tactical Assistant scenario maps - Sprint 005E

These 34 deployment diagrams were regenerated from complete rendered pages of
the user's authoritative Babylon 5: A Call to Arms Rulebook and Powers &
Principalities PDFs.

Sprint 005E replaces the earlier approximate crops. Each PNG contains the
entire printed deployment diagram, including all labels, measurements, zones,
borders, and portrait orientation where applicable. Surrounding scenario text
and page decorations were deliberately excluded.

The files are runtime reference assets only. They do not modify platform_data
or Database/Data/dfs.db.

Run tools/verify_scenario_map_assets.py from Application/Python to verify the
exact dimensions and SHA-256 digest of every map.
