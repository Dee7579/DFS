# Changelog

## 2.0.0-alpha2 — Platform Explorer

### Added

- Compact two-line platform navigator.
- Platform Explorer application identity.
- Resizable navigator/workspace layout.
- Platform result tooltips.
- Tactical Reference System subtitle.
- About dialog with database and runtime information.
- Dashboard database statistics.
- Startup splash screen.
- Keyboard shortcut to Platform Explorer.

### Changed

- Renamed Ship Viewer to Platform Explorer in the active desktop UI.
- Removed redundant database columns from the platform selection area.
- Improved default pane proportions and navigator usability.

### Preserved

- Existing importer, validator, database, generators, platform data, PDFs, and Codex.

## 2.0.1 Alpha 2 — Platform Explorer and Presentation Foundation

### Added

- Reset Platform Explorer Layout command and Ctrl+Shift+0 shortcut.
- DFS presentation-theme registry.
- DFS Design System and Presentation Engine architecture documents.

### Changed

- Splash screen now has a 1.5-second minimum display time.
- Platform Explorer defaults to 18% filters, 22% navigator, and 60% workspace.
- Splitter handles are wider and easier to identify.
- PDF toolbar is arranged in two rows to permit practical pane resizing.

### Fixed

- Weapons now display in DFS arc order: B, F, P, S, A, B(a), T.
- Original weapon order is preserved within each arc.
- Restrictive Phase 3C pane geometry is automatically replaced on first launch.

## 2.1.0-alpha1 — Game System Framework and Dashboard

- Application-level game-system registry and selector.
