# DFS Fleet Builder Sprint 002B.1

## Purpose

Improve the first Fleet Builder workspace after hands-on review without adding faction-specific construction rules prematurely.

## Changes

- Fleet Setup now occupies the left column above Available Platforms.
- Fleet Roster extends to the top of the right workspace.
- New, Open, Save, and Save As moved to the bottom command bar.
- Available-platform tooltips now include profile statistics, traits, weapons, craft, and service date.
- Budget feedback reports remaining FAP while legal.
- An INVALID label appears only when the FAP allowance is exceeded.
- Priority arithmetic now permits unused choices from a legal P&P split to be discarded.
- Priority results expose minimum FAP required, remaining FAP, and exceeded FAP.

## Scope deferred to Sprint 002C

- purchase groups
- two-for-one selections
- fighter replacements
- allied allowances
- faction-specific restrictions
