\# DFS Ship Sheet Generator MVP



\## Version 0.1 Goal



Generate printable ship sheets for Babylon 5: A Call to Arms Second Edition.



\## Primary Workflow



1\. Enter ship data.

2\. Save ship profile.

3\. Generate ship sheet.

4\. Export or print.



\## Supported in v0.1



\- Babylon 5 ACTA Second Edition

\- Ship name/class

\- Faction

\- Priority level

\- Speed, turn, hull, damage, crew, troops, craft

\- Traits

\- Weapons by arc

\- In service date

\- Source reference

\- Ship image

\- Printable sheet output



\## Not Supported in v0.1



\- Fleet builder

\- Campaign system

\- Victory at Sea

\- Battlefleet Gothic

\- Custom ship sharing

\- Full encyclopedia/lore system



\## Development Test Ship



Omega-class Destroyer



The Omega will be used as the first full test case because it has traits, weapons, fighters, multiple arcs, and enough complexity to prove the sheet generator works.



\## Project Rule



If a feature does not help generate B5 ACTA 2E ship sheets, it waits until a later version.
